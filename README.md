## ❓ Why EatLystic?

Managing your kitchen and pantry can be challenging — tracking what you have, when items expire, and how they affect your health goals. EatLystic helps by:

- 🗂️ Keeping an up-to-date inventory of pantry items, quantities, and expiry dates.  
- 🥦 Providing nutritional insights tailored to your dietary needs.  
- 🍳 Offering personalized meal suggestions and health recommendations.  
- ♻️ Helping you waste less food and optimize your nutrition intake.  

With EatLystic, you can **manage what you eat**, **maintain your health goals**, and **ensure your kitchen runs smoothly**.

## ✨ Features

### 1. 🥡 Pantry Management & 🧾 AI Bill Scanner
* **Manual-Free Entry:** Open your webcam or upload a photo to scan physical grocery bills directly. The built-in **AI OCR text parser engine** automatically logs item names, quantities, and purchase details right into your digital inventory.
* **Granular Fields:** Keeps records organized cleanly by categories, expiry trackers, and custom storage zones.

### 2. 🛒 Smart Cartify (With Price Comparison Analytics)
* **Dynamic Predictive Restocking:** Automatically generates smart grocery lists by evaluating expiring products, low stock thresholds, and user meal logs.
* **Cost Optimization Engines:** Analyzes identical shopping carts across multiple digital delivery and retail food networks, matching price indexes to yield the single most cost-effective direct order links online.

### 3. 🔥 Calorify
* Track remaining inventory caloric density versus daily consumption limits using real-time dynamic dashboard monitors.

### 4. 🍎 Nutrilog
* A visual micro/macro nutrition data analyzer. Simply flash barcodes in front of your live camera stream to extract food label metrics instantly via global nutrition databases.

### 5. 🏃 Trackify
* Answer onboarding questionnaires to construct baseline profiles capturing localized standard health variables (BMI, adaptive daily step-goals, active metabolic rate).

### 6. 🍲 Melaify
* **👨‍🍳 PantryChef:** Scans your real-time available ingredients to calculate actionable, immediate recipes.
* **🍴 MealChef:** Browse and filter broad collections of global cuisines.
* **📊 MacrosChef:** Tailors structural meal patterns directly around personal fitness benchmarks.
* **🤖 Eatstik:** Your companion AI chatbot, prepared to solve contextual recipe adjustments or calculate complex macro substitutes.

### 7. ⏳ Stockify
* Automated notification engine filtering items approaching expiration. Offers clean multi-format exports (📄 PDF checklists) to safely minimize home waste.

### 8. 🆘 Help Desk
* Comprehensive troubleshooting hubs, structured quick-read FAQs, and accessible contact frameworks.

## ⚙️ Installation & Setup


### 1. Clone the repository
```bash
git clone https://github.com/ShreyaVerma0407/EatLystic.git
cd EatLystic
```
### 2. Install Backend Dependencies
```bash
cd Backend
npm install
```
### 3. Install Frontend Dependencies
```bash
cd Frontend
npm install
```
### 4.Install Python Dependenices
```bash
cd cart
pip install -r requirements.txt
```

## 🚀 Running the Project

   * Frontend:

     ```bash
     cd Frontend
     npm run dev
     ```
   * Backend:

     ```bash
     cd Backend
     npm start
     ```
     ```bash
     cd cart
     streamlit run app.py
     ```

## 🛠️ Environment Variables

Make sure to create `.env` files for **both frontend and backend** with the following variables.



### ⚡ Frontend (`frontend/.env`)

```env
# API base URL (backend server)
VITE_API_BASE_URL=http://localhost:3001/api
VITE_STREAMLIT_URL=http://localhost:8501

# Default values for theme, language, etc. (non-secret stuff)
VITE_DEFAULT_THEME=light
VITE_DEFAULT_LANGUAGE=en

# Third-party API keys (replace with your own)
VITE_UNSPLASH_KEY=your_unsplash_key_here
VITE_EDAMAM_APP_ID=your_edamam_app_id_here
VITE_EDAMAM_APP_KEY=your_edamam_app_key_here
VITE_NINJAS_API_KEY=your_ninjas_api_key_here
VITE_USDA_API_KEY=your_usda_api_key_here
VITE_PEXELS_KEY=your_pexels_api_key_here
VITE_SPOON_KEY=your_spoonacular_api_key_here
```
### ⚡ Backend (backend/.env)

```env
# Server ports
PORT_backend=3001
PORT_frontend=3000

# MongoDB connection string (replace with your own)
MONGO_URI=your_mongodb_connection_string_here

# Email credentials (for Nodemailer or similar)
EMAIL_USER=your_email_here
EMAIL_PASS=your_email_password_here

# Third-party API keys (replace with your own)
EDAMAM_APP_ID=your_edamam_app_id_here
EDAMAM_APP_KEY=your_edamam_app_key_here
OCR_API_KEY=your_ocr_api_key_here
```
