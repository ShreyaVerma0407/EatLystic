## ✨ Features

### 🏠 Pantry Management

* 📦 **Pantry Page** – Track available items
* ➕ **Add Items with Calories & Nutrients**
* 📜 **Pantry Report** – View expired & safe items
* ✉️ **Email Notifications** for expired items
* 📄 **Download Pantry Report as PDF**

### 🛒 Shopping & Recipes

* 🛒 **Shopping Cart** – Collect expired/low items + recipe ingredients
* 👨‍🍳 **Recipe Generator**

  * **Pantry Chef** – Recipes from current pantry items
  * **Meal Chef** – All recipes, filter by cuisine / veg-nonveg / prep time
  * **Macros Chef** – Recipes suggested from **fitness quiz**

### 🍲 Recipe Interaction

* ❤️ **Liked Page** – Save your favorite recipes
* 🔥 **Trending Page** – Discover popular recipes
* ✍️ **Customise Recipe** – Create your own dish

### ⚡ Fitness & Nutrition

* 📊 **Nutrient Tracker** – Monitor consumed nutrients & calories
* 🏋️ **Fitness Tracker** – Evaluate fitness using **BMI + nutrient intake**

### 📢 Support & Feedback

* 💬 **Helpdesk Page** – Submit feedback
* 📞 **Contact Us** – Get in touch
* ❓ **FAQ Page** – Quick answers

## ⚙️ Installation & Setup

1. **Clone the repository**

   ```bash
 git clone https://github.com/ShreyaVerma0407/EatLystic.git
cd EatLystic

   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Run the project**

   * Frontend:

     ```bash
     cd Frontend
     npm run dev
     ```
   * Backend:

     ```bash
     cd Backend
     node start
     ```
